VCS - Version Control System
	Locale
	Centralizzato
	Distribuito

Git è un VCS Distribuito


Nel database locale (copia del repository scaricata) ciascun file può trovarsi in uno di tre possibili stati
  modified - il file è stato acceduto dal repository locale e modificato
  staged - il file precedentemente oggetto di modifica è contrassegnato come pronto per essere registrato allo stato definitivo
  committed - il file modificato è stato registrato nella nuova versione nel repository locale





git config --global user.name "Marcello-AlmaCorso"
git config --global user.email "m.moscato@almaviva.it"

git config --list
git config --global --list
git config --system --list
git config --local --list


git init  ## inizializza un repository vuoto, nella directory da cui è lanciato il comando


git clone <url_repository>
git clone --depth 20 <url_repository>  ## In questo caso si clona, nella directory da cui è lanciato il comando, il repository con una profondità di 20 aggiornamenti (20 commit)


git add <nomefile>
git add .
git add -A
git add -u  ## Aggiunge nell'area di stage i file tracciati dal repository che sono stati oggetto di modifica

git status

git commit -m "<messaggio>"


git log
git log --all --oneline --graph


git show <sha>


git diff <from> <to>
	dove <from> e <to> indicano le chiavi di commit, rispettivamente di partenza ed arrivo
git diff fromSha toSha
	restituisce la sequenza di commit effettuate per passare dalla chiave fromSha alla chiave toSha


git branch nomeRamo <sha>
git branch -d nomeRamo


git checkout <sha>
git checkout nomeRamo  ## Il nome del branch (nell'esempio nomeRamo) segue gli aggiornamenti effettuati nella evoluzione del ramo
	## Un ramo privo di etichetta sull'ultimo aggiornamento, sarebbe eliminato dal successivo intervento di garbace collection


git cherry-pick <sha>
	## Aggiunge, sul branch corrente, la commit relativa a quella identificata da <sha>


git rebase nomeRamo
	## Sposta il branch corrente su quello specificato da nomeRamo
		[Tutte le commit del branch corrente che non siano comuni al branch nomeRamo - corrisponde ad uno spostamento del branch corrente per posizionarlo su quello indicato da nomeRamo]

git rebase branchUno branchDue
	## Sposta, sopra branch branchUno, il branch branchDue


git merge nomeRamo
	## Unisce il branch corrente a quello individuato da nomeRamo, creando una modifica da rendere effettiva con una nuova commit
		[È logicamente simile all'operazione di rebase: i commit legati al branch nomeRamo divengono parte di quello corrente, ma questo non viene spostato]


git remote add nomeRepoRemoto <indirizzo>
git remote
git remote --verbose





git pull --rebase <nomeRepoRemoto>
	## Aggiunge preventivamente sul branch corrente, prima delle commit effettuate in locale, quelle del corrispondente branch remoto
	## Successivamente aggiunge le commit effettuate in locale non ancora su <repoRemoto>, ponendole in "rebase" sullo stesso branch


git push
git push origin master
git push -u origin --all


## più precisamente
git push
git push <nomeRepoRemoto> <nomeBranch>
git push -u origin --all

SSL Certificate Problem
---------------------------------------------------------------------------------------------------

https://komodor.com/learn/how-to-fix-ssl-certificate-problem-unable-to-get-local-issuer-certificate-git-error/

git config --global http.sslVerify false
	## disabilita la verifica delle credenziali con Certificati SSL

git config --global http.sslVerify true
	## abilita la verifica delle credenziali con Certificati SSL




Eliminazione degli ultimi commit dal repository locale
---------------------------------------------------------------------------------------------------

https://www.lucagrilli.com/annullare-commit-locali-recenti-git#:~:text=git%20reset%20HEAD~%20è%20il,poter%20effettuare%20nuovamente%20il%20commit.

N.B.: Il comando <git reset> ha varie opzioni - ricercare la più conveniente, prima dell'impiego
		... ATTENZIONE!!! ... Il comando va usato con cautele, poiché il suo effetto può essere irreversibile

Consultare il manuale di riferimento per il comando "git reset"
